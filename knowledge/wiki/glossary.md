# Glossary

Alias expansion for retrieval: maps terms between the vault's primary language and English (and between synonyms) so that both grep variants in Parallel Retrieval find the same pages. Retrieval infrastructure, not knowledge content — maintained during query and ingest operations.

Format:
```
- primary-language term = English term = further synonyms
```
